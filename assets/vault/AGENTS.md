# 个人知识库约定

先读 SCHEMA.md、SOURCE_OF_TRUTH.md 和 index.md，按任务查相关资料。

本库分为素材、知识库和个人档案。保留原始材料，第三方观点注明归属，不据此推断用户身份。个人档案只接受用户明确回答、记录要求和纠正；未知保持未知，推测单独注明，不混入事实。

用户通过 cy-vault 开启模块和作用范围后，在该范围内主动查资料、收录交给 Agent 处理的材料、实际交付的文稿与有依据的分析成果，并更新相关主题和索引。临时不保存、暂停和后续范围变更优先。仅创建空库或绑定目录不启用自动积累，也不追溯收录历史任务。

建档一次只问最有用的缺项，已有答案直接复用，可跳过、暂停和续接。自动保存实际回答及其整理稿，阶段性展示简短资料卡供纠正。

同组原文与校对稿分别保存并互链；改写与分析保留来源。主题页标注草稿，引用实际来源。学习进度依用户反馈、练习或复述记录，不以 Agent 已讲解推断掌握。

更新前读取当前文件和版本，保留人工修改；原始材料不可覆盖。写入后读回并更新 index.md，待保存不等于已保存。失败时先交付已完成的任务成果，保留待处理记录，恢复时先核对实际文件，避免重复写入。不自动提交 Git、发布到外部或创建定时任务。
