# 怎么使用

直接告诉 Agent 想做什么，例如“帮我分析这条视频”“按我的风格写稿”“继续上次学习的主题”。开启个人知识库和相关模块后，Agent 会主动查资料、积累成果和整理主题。

建档时一次回答一个问题即可，也可以跳过、暂停或之后继续。原始回答会保留，资料整理后会给你简短展示，发现不对直接纠正。

说“这次临时处理，不保存”可跳过本次收录；说“暂停自动积累”可暂停后续自动保存。说“增加创作模块”或“我想开始学一个主题”可以按需完善资料。

自己修改档案也可以，Agent 更新前会读取当前内容。材料处理完成但保存失败时，先拿到成果，Agent 会说明未保存的部分并保留补存进度。

基础档案供 AI 按需读取，不会训练模型，也不等于所有软件都有永久记忆。切换 Agent 或电脑后，要重新接入相应读取入口。定时整理需要另外开启。
