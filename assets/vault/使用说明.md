# 怎么使用

直接告诉 Agent 想做什么，例如“帮我分析这条视频”“按我的风格写稿”“继续上次学习的主题”。开启生活、工作、学习知识库后，Agent 会主动查相关资料、保存明确变化与成果，并整理主题。

新库会先问你想从生活、工作还是学习开始；选择只决定先聊哪块，三方向默认都会参与。访谈每轮问一个核心问题，直到你暂停、停止、拒答或换话题，不会因基础资料填齐就结束；普通任务仍先照常完成。原话会保留，事实、感受和推测分开，资料整理后会自然简短地提示重要变化，发现不对直接纠正。

说“这次临时处理，不保存”可跳过本次收录；说“暂停自动积累”可暂停后续自动保存。说“我最近开始做一个新项目”或“我想学一个新主题”就可以补充对应资料。

公共个人档案放在 `生活/个人档案/`；工作项目与账号风格继续留在各自场景。迁移旧库前，Agent 会先读规则和全部内容，给你完整文件映射与恢复预览；你确认一次后才备份、整理、更新索引和链接并逐项核验，保留原始历史。自己修改档案也可以，Agent 更新前会读取当前内容。材料处理完成但保存失败时，先拿到成果，Agent 会说明未保存的部分并保留补存进度。

资料只在你选择的范围内使用。可以让所选 Agent 的日常相关聊天参与，也可限制在本套件工作区；实际是否在新聊天读取，仍取决于宿主。知识库入口不是后台事件监听，也不会自动创建定时任务。

基础档案供 AI 按需读取，不会训练模型，也不等于所有软件都有永久记忆。切换 Agent 或电脑后，要重新接入相应读取入口。
