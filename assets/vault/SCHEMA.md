# 组织与文档

- 生活/：生活背景、经历、价值与决策、健康和日常、人际与家庭、财务条件、目标规划；公共个人档案放在 `生活/个人档案/`。
- 工作/：职业、项目、经营和创作。项目或账号的资料与风格留在各自场景下。
- 学习/：学习目标、基础资料、讲解与练习、实际应用和反馈。
- 三方向的内部目录按实际需要生长。每方向内可保存原始材料、校对稿、成果、主题与学习记录；原文和衍生稿分开保存并互链。
- index.md：根目录导航入口，列出生活、工作、学习及实际生成的材料组和主题页。人工维护区域保留。

文本使用 UTF-8。每份整理材料需有标题、来源及适用状态。主题页记录更新时间、草稿/已审和实际 sources；更新时间不能代替事实验证时间。人物观点注明归属，来源材料不能提升为用户事实。

生活建档按用户当下目标逐步了解六个方面，不使用固定问卷；工作项目与账号范围清楚隔离；学习按目标、基础、讲解、练习、应用和反馈推进。主题目录按实际内容需要建立，不预建空模块。

.cy-vault.json 标识新建库模板；.cy-vault-runtime/ 保存本地写入器的串行锁和目录记录。建档进度、原始回答快照、待处理事务和写入回执在对应工作区的 .local/vault/。它们属于用户数据，不进入 Skill 安装包。
