# 组织与文档

- 素材/：原始输入、校对稿、衍生文稿与来源记录。按实际任务建立主题或材料组；原稿和改写稿分别保存。
- 知识库/：可持续修订的主题、方法、案例与学习笔记。AI 整理保持草稿。
- 个人/档案/：用户明确提供的个人背景、目标、协作偏好与模块资料。默认基本资料.md；如已有权威档案，直接连接原位置。
- index.md：导航入口。自动积累区由写入器更新，其外的人工内容保留。

文本使用 UTF-8。每份整理材料需有标题、来源及适用状态。主题页记录更新时间、草稿/已审和实际 sources；更新时间不能代替事实验证时间。人物观点注明归属，来源材料不能提升为用户事实。

创作模块按需组织对标、选题、文稿和复盘；学习模块按需组织目标、材料、主题、问题和学习反馈。目录用到时创建。

.cy-vault.json 标识新建库模板；.cy-vault-runtime/ 保存本地写入器的串行锁和目录记录。建档进度、原始回答快照、待处理事务和写入回执在对应工作区的 .local/vault/。它们属于用户数据，不进入 Skill 安装包。
