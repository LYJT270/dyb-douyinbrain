# 个人知识方向：生活、工作与学习

[English](personal-domains.en.md)

本文由 [个人知识库指南](personal-vault.md) 按需引用。三个方向是持续交流的路线图，不是必须填完的调查表。新库第一次只让用户选择先从生活、工作、学习中的哪一块开始；新库默认开启三方向。旧库保留既有收录授权，只有用户明确扩大范围后才参与新方向；明确停用某方向后通过 `kb module <domain> --off` 记录。每轮只问一个最有用的核心问题，先检查已有材料，再依据上一轮回答继续。用户暂停、停止、拒答或换话题时照做；不要因基础资料齐全而结束。

## 生活

按当前目标选择最相关的一块，问题使用通用、原创的表达，不复制第三方题库、文章正文或个人资料：

- **背景与经历：** 哪些经历最影响你现在看待事情或做选择的方式？
- **价值、决策与动力：** 两件都重要的事发生冲突时，通常什么会帮你决定先顾哪边？
- **健康、日常与节奏：** 一天里什么事情最影响你的精力或状态？
- **人际与家庭：** 做重要安排时，哪些关系或共同责任通常需要一起考虑？
- **财务与现实条件：** 规划事情时，有哪些时间、预算或责任上的限制需要纳入？
- **目标与规划：** 你当前最想推进哪件事，最近一步打算是什么？

用户愿意分享多少就记录多少；敏感或未知内容不补猜。把可核实事实、用户感受和 Agent 推测分开保存。

## 工作

围绕用户当前最相关的职业、项目、经营或创作展开。先读已有项目材料与被认可的作品，再问一个能推进当前任务的问题，例如当前负责什么、目标受众是谁、近期结果如何、项目受哪些资源或时间约束。工作项目或账号的背景、风格和决策只在其场景范围内引用，不当作所有场合都适用的个人偏好。

## 学习

按连续过程推进：先明确**学习目标与基础资料**，再通过**讲解、练习、应用和反馈**不断调整。只记录用户实际展示的理解、练习、应用结果和反馈；Agent 讲过内容不等于用户已经掌握。问题一次一个，以当前可做的下一步为中心。

## 跨方向与暂停

明确任务优先；普通任务不自动变成访谈。已开启范围内遇到清晰的新事实、状态变化、目标变化和实际结果，可主动保存并在结果中简短说明。完成当前方向的一段后，可先查已有和导入资料，再偶尔邀请用户开始未启动方向。跳过、拒答或暂停的主题保持当前状态，不反复提醒。
