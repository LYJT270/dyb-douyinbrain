## 独立隔离迁移与实际交付

独立 Agent 使用合成用户请求和冻结候选完成流程，未修改候选源码。候选冻结时 `VERSION` 仍为 `1.5.0`，记录标识为 `1.5.0 unreleased CY rename`；这份证据验证改名实现与业务行为，v1.6.0 标签包另在公开发布阶段核对。

1. 从旧版归档安装 1.5.0，用合成文稿实际执行 `plan-text → confirm → run`，产生等待校对的任务。
2. 调用新安装器时不传 `Workspace` 或 `StateDirectory`，自动发现并沿用旧登记。7 个新入口和 6 个旧转发入口可运行。
3. 迁移时读回旧任务记录、来源快照和输入原文，内容保持一致；随后交替使用新旧入口完成同一任务的校对、口播登记和交付。任务 ID 未改变，最终 `resume` 返回 `finished=true`，交付正文保留原稿的四个提醒。
4. 在隔离工作区建立个人知识库，记录合成用户明确回答并开启创作模块，保存原文、校对稿、口播交付和有来源的主题草稿。
5. 逐一读取 6 份知识库内容文件，与回执哈希全部一致；索引包含保存内容。另一个 CLI 进程能找到档案和相关主题，入口区块完整性匹配，`pending` 为空。

原始报告位于开发环境的 `.scratch/cy-rename/forward-test/report.md`，原始回执位于同目录 `receipts/`，不随分发包携带。关键回执为：

- `07-cy-install-receipt.json`：新入口、沿用工作区和兼容入口备份。
- `08-migration-readback.json`：迁移时旧任务与输入的完整性读回。
- `18-finished-via-legacy-root-result.json`：旧主入口读回同一任务完成状态。
- `25-context-final-result.json`：独立 CLI 进程的档案、检索、范围及待处理状态。
- `26-final-verification.json`：6 份知识库文件哈希、入口完整性及验证边界。

## 本机宿主列表

本机 Codex 原生 `skills/list` 已读回 6 个已有正式入口和旧名称兼容入口，中文显示名称与说明可读取。新增 `CY-vault` 没有装入日常环境；完整 7 入口的安装、运行和知识库行为证据来自隔离环境。

列表可见性不等于所有宿主自动发现，也不等于每个宿主的新聊天会读取知识库入口。先前个人知识库的隔离 Codex CLI 工作区会话证据见[个人知识库本地验收](personal-vault.md)，其原有范围和日期保持不变。

## 未验证范围

- 独立迁移使用 `-SkipDependencies`，不证明完整依赖安装或全新电脑首次下载环境成功。
- 本轮没有真实云端识别、真实语音 Key 解密或真实媒体下载；使用合成资料，不读取或写入实际用户知识库。
- 新旧入口跨 CLI 进程续办不等于 Codex 桌面完整重启、全部宿主自动发现或全局知识库作用域验收。
- 本地包、源码测试、PR CI、合并后 CI、标签发布与公开 ZIP 下载各自需要对应回执，不能互相代替。

## English summary

The brand and personal-knowledge candidate passed 208 full-regression tests. Two subsequent review fixes passed 28 personal-knowledge tests; independent review passed 32 focused checks with no remaining blocker. Local regression after those fixes passed 210 tests in 256.865 seconds. The first PR CI then exposed a Windows Server partial-directory move when a legacy file was locked. Backup and rollback now use the same whole-directory rename as suite installation. All 4 brand-migration checks passed in 30.216 seconds with the original full-snapshot assertions retained; final-commit CI results are recorded in the public release appendix.

An independent isolated migration installed old 1.5.0, discovered registration without Workspace / StateDirectory arguments, used 7 new entries and 6 legacy forwarders, and finished the same text task through both names. All 6 saved knowledge files matched their receipt hashes, a fresh CLI process retrieved profile and topic context, and no pending writes remained. The frozen candidate still carried a 1.5.0 version marker; public 1.6.0 package evidence is separate.

The trial used `-SkipDependencies` and synthetic data. It did not establish complete dependency installation, real credential decryption, cloud speech, live-media acquisition, or discovery across all hosts. The everyday Codex host listed 6 existing primary entries and legacy entries; the new vault entry was tested in isolation, not installed there. The table above is the pre-publication snapshot. Final CI, tag, source-commit and public ZIP verification receipts are maintained in the public verification appendix of the [v1.6.0 Release](https://github.com/ScarfaceAI/CY-CharmYee/releases/tag/v1.6.0); published tags and packages remain unchanged.
