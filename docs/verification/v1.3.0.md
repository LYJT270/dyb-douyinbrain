# 1.3.0 本地候选验收 / Local candidate verification

2026-11-06 的本机验收快照。此候选尚未推送，也未运行本次 GitHub CI 或公开发布；本机验证不等于用户验收。为保护素材和账户，本记录仅保留匿名汇总，不列原始链接、作者身份、个人路径或凭据。

## 中文

### 真实素材与识别

- 使用固定的 14 条公开视频比较新音轨获取：旧版 1.2.0 对照为 **0／14**，本地候选版匿名路径为 **7／14**。其余 7 条报告 `metadata_unavailable`，没有将其判成必须登录。该样本不能代表所有作品的可用率。
- 14 条候选版获取全批耗时 329.328 秒，单条获取耗时 34.375～68.594 秒；没有触发 90 秒获取超时，最多同时使用 2 个获取工作进程。两个工作进程最终均报告 `active_processes=0`。
- 从获取成功的素材中选择 3 名不同作者的作品，发起 3 次新的豆包语音请求，均成功；提交音频累计 139.6723125 秒。这是实际云端识别，非缓存复用或模拟请求。
- Agent 实际通读 3 篇识别稿并查看 29 帧，另存校对稿，通过 `deliver` 交付带 UTF-8 BOM 的合并 TXT；3 份机器原稿的哈希均保持不变。**没有听音复核**，少量词句仍在校对检查记录中标为未解疑点；看图不等于核实声音。
- 原任务与配置的保护哈希在本轮前后保持不变。

### 安装与回归

- Windows 隔离环境中实测旧版单套设置迁移和旧名的已有文稿入口；假凭据、原任务及定制配置保留。发现多个不同工作目录时返回 `needs_workspace_choice`，原安装保持不变。
- 独立模拟演练包含 3 条素材：初次成功条目保留原序号 1、3，续跑后得到 1、2、3；只有失败条目新增 1 次模拟 ASR，成功结果复用。这是模拟回归，不是额外的真实付费请求。
- 最终本地全量测试通过 93 项（48.655 秒），覆盖 `--cached-only` 禁止补取、音轨绑定异常不提交付费请求，以及工作数据内嵌旧 Skill 目录时原位保留的迁移。

本轮没有验证真实 DeepSeek 或 Claude 的新安装会话，也没有提供真实作者主页完整分页的验收证据。没有听音核查的内容保持未解疑点；平台变化或不同素材可能产生不同获取结果。

## English

This is a local verification snapshot from November 6, 2026. The candidate has not been pushed, run through this candidate's GitHub CI, or publicly released; local checks do not constitute user acceptance. To protect material and accounts, this record contains anonymous summaries only, with no source links, author identities, personal paths, or credentials.

### Live material and recognition

- New-audio acquisition was compared on the same fixed set of 14 public videos: the 1.2.0 baseline obtained **0/14**, and the local candidate's anonymous path obtained **7/14**. The other seven returned `metadata_unavailable` and were not classified as requiring login. This sample is not a general success rate for all posts.
- The candidate's batch took 329.328 seconds, with individual acquisition times of 34.375–68.594 seconds. No 90-second acquisition timeout occurred, and at most two acquisition workers ran concurrently. Both workers ended with `active_processes=0`.
- Three posts from different authors were selected from the acquired material. Three new live Doubao requests succeeded, covering 139.6723125 seconds of audio in total; these were not cached or simulated recognition results.
- The Agent read all three transcripts, actually viewed 29 frames, saved reviewed versions separately, and used `deliver` to produce a merged UTF-8 BOM TXT. Hashes of all three original machine transcripts remained unchanged. **Audio was not listened to**; a few phrases remain uncertain in the review record. Viewing frames does not verify speech.
- Protected hashes for the pre-existing tasks and configuration were unchanged.

### Installation and regression

- A Windows isolated environment was used to test migration from a single legacy configuration and the old-name entry with existing text; a fake credential, existing tasks, and customized configuration were preserved. Multiple differing workspaces returned `needs_workspace_choice` without changing the existing installation.
- An independent simulated three-item exercise retained successful original item numbers 1 and 3 on the first run, then produced 1, 2, and 3 on resume. Only the failed item added one simulated ASR request; successful results were reused. This was a simulation, not an additional paid live request.
- The final local full suite passed 93 tests in 48.655 seconds, including `--cached-only` preventing fetches, invalid audio bindings preventing paid requests, and migration preserving a workspace nested inside the legacy Skill directory.

This round did not verify real new-install sessions in DeepSeek or Claude, and it did not provide evidence of complete real creator-profile pagination. Speech that was not listened to remains uncertain; platform changes and different material may produce different acquisition results.
