## English

This is a historical verification snapshot from November 5, 2026, not a live status. It records evidence for an existing release and does not create a new release.

- Release: [v1.2.0](https://github.com/ScarfaceAI/dyb-douyinbrain/releases/tag/v1.2.0), neither draft nor prerelease, from source commit `14f5e2ddec9aaeb8c1d67eb37b879b77fd043baf`, merged through [PR #7](https://github.com/ScarfaceAI/dyb-douyinbrain/pull/7).
- [PR CI 42075021699](https://github.com/ScarfaceAI/dyb-douyinbrain/actions/runs/42075021699), [main CI 42075525799](https://github.com/ScarfaceAI/dyb-douyinbrain/actions/runs/42075525799), and [tag/release CI 42075943296](https://github.com/ScarfaceAI/dyb-douyinbrain/actions/runs/42075943296) passed. The tag CI log records 79 passing tests in 20.040 seconds; the local full suite passed 79 tests in 41.007 seconds.
- Tag CI installed in a fresh isolated directory and delivered existing text without an API key. `live_asr_requests=0`; no live speech recognition request was made.
- Public ZIP `dyb-douyinbrain-windows-v1.2.0.zip`: 2,194,587 bytes, 73 files, SHA-256 `15459deb18911a3d592b64f8eb4693ce47bd80136cc69edfbc75edc40f9c4abf`. Both the tag CI public download check without credentials and the local `scripts/verify_release.py --download` returned `status="verified"` and `public_download=true`.
- A live anonymous acquisition attempt with the new public implementation used one existing public video and no saved account state. It returned `metadata_unavailable`, did not misclassify the result as `login_required`, opened no visible window, and made no ASR request. Acquisition did not succeed, so this does not establish successful anonymous transcription.

Not verified: the full live path from anonymous acquisition through paid ASR, complete pagination of a real creator profile, or real sessions for each Agent.
