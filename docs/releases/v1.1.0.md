# 抖音脑 Douyin-brain 1.1.0

2026-11-05 · Windows

## 中文

抖音脑是 Windows 本地 Agent Skill，可将抖音视频或本地音视频转写、校对、分析和整理为口播稿，也可处理已有文稿。

### 本次更新

- 开始新任务时检查 GitHub 最新正式版；发现新版会提示，但不会自行安装。检查使用 24 小时缓存；检查失败不会阻断原任务。
- 用户明确要求更新时，验证官方安装包、SHA-256 和包内清单，再使用当前 Skill 位置、已有工作目录和本机状态安装；已有本地程序改动保留备份。
- 增加中英文维护与发布指南，以及发布预检和公开安装包校验流程。

**1.0.0／1.0.1 用户需要先手动安装本版一次**，之后才能收到新版提示并使用自然语言更新：下载 [1.1.0 Windows 安装包](https://github.com/ScarfaceAI/dyb-douyinbrain/releases/tag/v1.1.0)并解压，双击 `install.cmd`；也可以将安装包交给有本地文件和终端能力的 Agent。已有用户沿用原安装参数，完成本地检查后让 Agent 重新读取 Skill，或开启新会话。

以后需要更新时，可对 Agent 说「`@dyb-douyinbrain 更新`」「`$dyb-douyinbrain 更新`」或「使用 dyb-douyinbrain 更新自己」。详细步骤见[升级指南](https://github.com/ScarfaceAI/dyb-douyinbrain/blob/v1.1.0/docs/RELEASING.md#已有用户如何升级)。

### 已验证

- 55 项本地自动测试通过，覆盖版本缓存、离线检查、重复更新、安装包校验、数据保留，以及安装失败和超时后的处理等场景。
- 使用真实安装器，将隔离环境中已有的 1.0.0 安装升级至本地 1.1.0 候选包；原配置和任务哨兵保持不变，旧程序备份存在，本地入口检查通过。

此次预发布升级使用本地候选包代替 Release 网络来源；公开发布后将由发布流程另行下载并验证公开安装包。安装失败且已有登记的备份时会恢复旧程序；如果无法确认安装子进程已结束，会保留锁和现场供检查，不强行覆盖。

真实付费语音识别、作者主页的真实完整分页，以及各 Agent 的实际交互仍未逐一验收。本机 `doctor` 不能代替这些验证。

## English

Douyin-brain is a Windows-local Agent Skill for transcribing, proofreading, analyzing, and adapting Douyin videos or local media, and for working with existing text.

### What's new

- Checks GitHub for a newer stable release when a new task begins and notifies you without installing it automatically. Checks use a 24-hour cache; a failed check does not block the original task.
- When you explicitly request an update, verifies the official package, SHA-256, and bundled manifest before installing at the current Skill location with the existing workspace and local state. Existing local program changes are backed up.
- Adds Chinese and English maintenance guides, release preflight, and public package verification.

**Users of 1.0.0 and 1.0.1 must first install this version manually once** to receive update notices and use natural-language upgrades afterwards. Download and extract the [1.1.0 Windows installation package](https://github.com/ScarfaceAI/dyb-douyinbrain/releases/tag/v1.1.0), then double-click `install.cmd`, or give the package to an Agent with local file and terminal access. Existing users should reuse their original installation arguments, then ask the Agent to reread the Skill or start a new conversation after local checks.

For a later update, say “`@dyb-douyinbrain 更新`”, “`$dyb-douyinbrain 更新`”, or “Use dyb-douyinbrain to update itself.” See the [upgrade guide](https://github.com/ScarfaceAI/dyb-douyinbrain/blob/v1.1.0/docs/releasing.en.md#upgrading-an-existing-installation).

### Verified

- 55 local automated tests passed, covering version caching, offline checks, repeated updates, package verification, data preservation, and handling of installation failures and timeouts.
- The real installer upgraded an existing isolated 1.0.0 installation to a local 1.1.0 candidate. Its original configuration and task sentinel remained unchanged; the old program backup existed and the local entry check passed.

This prerelease upgrade used a local candidate package in place of the network Release source. After publication, the release process will separately download and verify the public package. When an installation fails and a recorded backup is available, the previous program is restored. If the installer subprocess cannot be confirmed to have exited, the lock and state are retained for inspection instead of forcing an overwrite.

Live paid speech recognition, complete pagination of a real creator profile, and individual interactive sessions across Agents have not yet been fully verified. Local `doctor` checks do not establish those results.
