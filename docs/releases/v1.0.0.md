# 抖音脑 Douyin-brain 1.0.0

2026-11-05 · Windows

## 中文

抖音脑是本地运行的 Agent Skill：将抖音链接、作者主页或本地音视频交给 Agent，使用你自己的豆包语音 API 转写，再按需校对、分析、改成口播稿或批量导出 TXT。已有文稿也可以直接处理；只有明确要求时才写入知识库。

### 安装与使用

下载本版本的 Windows 安装 ZIP 并解压，双击 `install.cmd`，或将安装包／仓库源码目录交给具备本地文件和终端能力的 Agent，按 [INSTALL.md](https://github.com/LYJT270/dyb-douyinbrain/blob/v1.0.0/INSTALL.md) 自动安装。无需预先安装 Python；安装器尝试准备所需环境。语音识别需要自备豆包语音 Key，费用以服务商和账户实际规则为准。没有 Key 时可以先处理已有文字稿。

本版本提供 DeepSeek Harness、Codex、Claude Code、Gemini CLI、Cursor、OpenCode 等 Agent 的安装适配。默认使用共享 Skill 目录，并在适用时尝试建立 Claude 桥接；自动发现方式取决于各 Agent 的配置。

抖音素材通过独立编写的 Playwright 浏览器网络响应解析获取，必要时用 yt-dlp 回退单条作品。需要登录或验证码时由用户本人完成。作者主页若未能翻到末尾，结果会标为不完整。

### 已验证

- 42 项本地自动测试通过，覆盖真实 FFmpeg 处理、付费请求重试、原文保护、路径、重复安装、同名安装备份及 Claude 共享联接等场景。
- 在独立新目录完成完整依赖安装，本地检查结果为 `environment_ready`，入口验证为 `local_entry_verified=true`；未配置 Key 时状态为 `awaiting_api`。

- 无 Key 的已有文稿已通过原稿留底、校对登记和 TXT 交付的端到端检查。
- 一个公开抖音视频样例已完成真实元数据解析与 FFmpeg 音轨提取，约 19.7 秒音频拆成 2 个片段；未调用付费识别。

### 当前边界

- 作者主页的真实完整分页尚未实测；平台页面或访问策略变化仍可能需要更新解析器。
- 尚未调用真实豆包语音 API，本地检查通过不能证明云端权限、余额或识别结果。
- 跨 Agent 的真实交互会话尚未逐一验证；安装适配不等于各 Agent 的实际使用验收。

## English

Douyin-brain is a Windows-local Agent Skill. Give it Douyin links, creator profiles, or local media to transcribe using your own Doubao Speech API, then request proofreading, analysis, spoken scripts, or a numbered TXT batch. It can also process existing text. Knowledge-base archiving occurs only when requested.

### Install and use

Download and extract the Windows installation ZIP for this version, then double-click `install.cmd`. Alternatively, give the installation package or repository source to an Agent with local file and terminal access and follow [INSTALL.md](https://github.com/LYJT270/dyb-douyinbrain/blob/v1.0.0/INSTALL.md). Python is not required in advance; the installer attempts to prepare the environment. Speech recognition requires your own Doubao Speech key and is subject to the provider's pricing and account terms. You can process existing text without a key.

This release provides installation adapters for DeepSeek Harness, Codex, Claude Code, Gemini CLI, Cursor, OpenCode, and compatible Agents. The default uses a shared skill directory and attempts a Claude bridge where appropriate; discovery depends on each Agent's configuration.

The independent downloader uses Playwright browser network responses and can fall back to yt-dlp for individual posts. Users complete any required login or CAPTCHA themselves. Creator-profile results are marked incomplete if pagination does not reach the end.

### Verified

- 42 local automated tests passed, covering real FFmpeg processing, paid-request retry behavior, original preservation, path handling, repeat installation, backups for existing installations, and Claude shared-directory linking.
- A complete dependency installation in a new isolated directory produced `environment_ready` and `local_entry_verified=true`; without a key, the status was `awaiting_api`.

- Existing-text import, source preservation, review registration and TXT delivery passed end to end without an API key.
- One public Douyin video passed live metadata extraction and FFmpeg audio extraction (approximately 19.7 seconds, 2 chunks), with no paid recognition request.

### Current limits

- Complete creator-profile pagination has not been verified against a live profile. Platform and access changes may require extractor updates.
- No live Doubao Speech API request was made. A successful local check does not establish cloud permissions, account balance, or recognition quality.
- Real interactive sessions have not been individually verified across all supported Agents; an installation adapter alone is not acceptance of an Agent's complete workflow.
