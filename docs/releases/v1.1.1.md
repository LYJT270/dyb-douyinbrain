# 抖音脑 Douyin-brain 1.1.1

2026-11-05 · Windows

## 中文

此补丁修复部分 Windows 环境因系统证书链无法验证 GitHub，导致版本检查或更新下载失败的问题。

程序仍默认使用系统证书。仅当只读 GET 请求遇到 `SSLCertVerificationError`，且 `SSL_CERT_FILE` 与 `SSL_CERT_DIR` 均未设置时，才使用 `certifi 2026.10.23` 提供的 Mozilla 信任根重试同一请求；重试仍校验证书链和域名，不修改系统证书库。用户明确配置自定义 CA 时继续使用该配置。

已安装 1.1.0 的用户可继续通过「`@dyb-douyinbrain 更新`」「`$dyb-douyinbrain 更新`」或「使用 dyb-douyinbrain 更新自己」请求更新。**如果 1.1.0 因证书错误无法更新**，请从 [1.1.1 Release 页面](https://github.com/ScarfaceAI/dyb-douyinbrain/releases/tag/v1.1.1)下载新版 ZIP，使用同一 Windows 用户和原安装参数运行安装器；完成本地检查后，让 Agent 重新读取 Skill 或开启新会话。

1.0.0／1.0.1 用户仍需先手动安装一次本版或包含更新功能的较新版，才能使用后续更新提醒与自然语言升级。更多步骤见[升级指南](https://github.com/ScarfaceAI/dyb-douyinbrain/blob/v1.1.1/docs/RELEASING.md#已有用户如何升级)。

真实付费语音识别、作者主页的真实完整分页和各 Agent 的实际交互仍未逐一验收。

## English

This patch fixes update checks or downloads failing on some Windows systems when the system certificate chain cannot validate GitHub.

The system trust store remains the default. Only when a read-only GET raises `SSLCertVerificationError` and neither `SSL_CERT_FILE` nor `SSL_CERT_DIR` is set does the program retry the same request with the Mozilla trust roots provided by `certifi 2026.10.23`. The retry still verifies the certificate chain and hostname and does not modify the system trust store. Explicitly configured custom CAs remain in use.

Users on 1.1.0 can continue to request updates with “`@dyb-douyinbrain 更新`”, “`$dyb-douyinbrain 更新`”, or “Use dyb-douyinbrain to update itself.” **If a certificate error prevents 1.1.0 from updating**, download the new ZIP from the [1.1.1 Release page](https://github.com/ScarfaceAI/dyb-douyinbrain/releases/tag/v1.1.1) and run the installer as the same Windows user with the original installation arguments. After local checks, ask the Agent to reread the Skill or start a new conversation.

Users on 1.0.0 or 1.0.1 still need to manually install this version, or a later version with the updater, once before using update notices and natural-language upgrades. See the [upgrade guide](https://github.com/ScarfaceAI/dyb-douyinbrain/blob/v1.1.1/docs/releasing.en.md#upgrading-an-existing-installation).

Live paid speech recognition, complete pagination of a real creator profile, and individual interactive sessions across Agents have not yet been fully verified.
