# 承意 · CY-CharmYee 1.6.0

2026-11-13 · Windows

## 中文

**承你所想，会你所意。** 本版将原抖音脑套件统一命名为「承意 · CY-CharmYee」，保留媒体处理、创作和续办能力，并加入可选个人知识库：先通过简短对话建立基础资料，再围绕实际任务增配创作、学习和知识积累。

### 功能与变化

- **统一品牌与入口。** 总入口为 `cy-charmyee`，六个子入口为 `cy-transcribe`、`cy-analyze`、`cy-download`、`cy-write`、`cy-knowledge`、`cy-vault`。界面展示使用 `CY-` 前缀与中文功能说明；安装包、配置窗口、中英文文档和更新校验同步采用新名称。
- **可选个人知识库。** `CY-vault` 可建立新库或接入已有库，通过可跳过、暂停和续接的对话记录用户明确提供的背景、目标与偏好。新库从素材、知识主题和个人档案三层开始；已有库保留目录、现行规则和权威档案。
- **按任务逐步增配。** 创作和学习模块按实际需要开启。选定范围内，Agent 主动查找相关资料、保存可复用成果并更新主题，无需每次再询问是否入库。可选择工作区或所选 Agent 的日常聊天范围；“本次不保存”和暂停继续优先。
- **保存过程可以续办。** 原话、来源和衍生内容分别保留，写入检查实际文件版本并读回核对索引。冲突、外部写入等待或存储失败保留真实待处理项；先交付已完成成果，再按当前文件状态补存。个人知识库通过 `kb context` / `kb retry` 续办。
- **保留旧环境。** 新安装使用 `cy-*` 入口，已有登记、任务、媒体缓存、知识库选择和凭据继续沿用。确认属于本套件的旧 `dyb-*` / `douyin-brain` 路径转为兼容入口，替换前保留备份；`CY_*` 环境变量优先，旧 `DYB_*` 仍可读取。
- **保护规则与纠正记录。** Windows 下按实际路径识别规则和索引，拒绝使用大小写变体将其当普通材料覆盖。用户从答案 A 改为 B、之后明确恢复 A 时，新的纠正会生效并保留原始回答；紧邻的相同回答重试仍复用已有记录。

知识库不会因安装而自动启用，不自动扫描历史文件，不把第三方经历或 AI 推测当用户事实，也不随建库启用定时任务或外部发布。具体流程见[个人知识库](../../references/personal-vault.md)和[套件路由](../../references/suite.md)。

### 首次迁移与后续更新

**所有旧品牌版本首次切换到承意，都要运行一次新安装器，包括已有自动更新功能的 1.1.0–1.5.0。** 旧更新器固定校验旧产品 ID、ZIP 名称和包内目录，不能用旧 `update --apply` 直接安装新品牌包。

1. 从[官方 Release](https://github.com/ScarfaceAI/CY-CharmYee/releases)取得 `cy-charmyee-windows-v1.6.0.zip` 及 `.zip.sha256`，核验后解压，确认 `bundle.json` 中 `name=cy-charmyee`。
2. 让 Agent 用同一 Windows 用户运行新包的 `scripts/install.ps1`，或双击 `install.cmd`；自定义安装沿用原 Agent、SkillsRoot 和状态位置参数。单套已有登记会自动发现，多个工作区再选择一次，不合并任务。
3. 根据安装回执核对工作区、入口和备份，运行本地 `doctor`，再用已有文稿确认实际续办。让 Agent 重读新 `SKILL.md` 或开启新会话。

已安装承意后，后续版本使用新入口的 `update --apply`。旧 Release 标签、资产名和历史记录保持原样；发布本版不会自动升级维护者的日常安装。详见[安装指南](../../INSTALL.md)及[品牌迁移](../../references/brand-migration.md)。

### 验证范围

发布前本地完整回归通过 **210 项测试**；后续 CI 和 GitHub 审查修正了占用文件迁移、过期分析、档案来源链接及索引恢复问题，**4 项迁移专项、33 项知识库专项**通过。全套现有 **215 项测试**，最终提交的完整 CI 与公开安装包证据见[验收记录](../verification/v1.6.0.md)和本页公开验证附录。7 个 Skill 的格式校验通过，独立隔离试用从旧 1.5.0 安装自动找到登记，不传 Workspace / StateDirectory，使用新旧入口交替完成同一文稿任务，并逐一读回核验 6 份知识库内容文件的哈希。

上述安装试用使用 `-SkipDependencies` 和合成资料，不代表完整依赖安装、真实凭据解密、云端识别或所有宿主自动发现均已验证。本机原生 `skills/list` 读回的是 6 个已有正式入口及旧兼容入口，新增 `CY-vault` 未装入日常环境；完整 7 入口的安装与使用证据来自隔离环境。CI、标签和公开 ZIP 校验以实际发布阶段回执为准。

## English

**承你所想，会你所意。** Version 1.6.0 renames the former Douyin-brain suite to **承意 · CY-CharmYee**, retains its media, creative, and recovery workflows, and adds an optional personal knowledge base. Start with a short profile conversation, then enable creative, learning, and collection features as real tasks need them.

### Features and changes

- **Consistent brand and entries.** The coordinator is `cy-charmyee`, with `cy-transcribe`, `cy-analyze`, `cy-download`, `cy-write`, `cy-knowledge`, and `cy-vault`. Display names retain the `CY-` prefix and Chinese capability labels. Packages, configuration windows, bilingual documentation, and update validation use the new identity.
- **Optional personal knowledge.** `CY-vault` creates a new library or connects an existing one. Resumable conversations record explicitly supplied background, goals, and preferences; questions can be skipped or paused. New libraries start with sources, knowledge topics, and a personal profile. Existing structures, rules, and canonical profiles remain authoritative.
- **Modules added during work.** Enable creative or learning modules as needed. Within the chosen scope, the Agent retrieves relevant context, preserves useful outcomes, and updates topics without requesting archiving permission every time. Choose the suite workspace or everyday chats in a selected Agent; unsaved tasks and paused collection remain respected.
- **Recoverable writes.** Preserve original answers, sources, and derived content separately. Check actual file versions and read back files and indexes. Conflicts, pending external writes, and storage failures retain real pending records; completed task outcomes can be delivered while saving resumes later. Use `kb context` and `kb retry` for personal-knowledge recovery.
- **Existing environments preserved.** Fresh installations use `cy-*`, while registered workspaces, tasks, caches, library choices, and credentials remain usable. Verified `dyb-*` and `douyin-brain` installations become compatibility forwarders with backups. `CY_*` environment values take precedence, with legacy `DYB_*` values still accepted.
- **Protected rules and corrections.** Windows path-equivalence checks prevent ordinary material writes from replacing rules or indexes through case variants. An explicit profile correction from A to B and back to A is recorded and applied; original answers remain available, while immediate identical retries reuse their records.

Installing does not automatically enable the library, scan historical files, infer user facts from third-party material, start schedules, or publish externally. See [personal knowledge](../../references/personal-vault.en.md) and [suite routing](../../references/suite.en.md).

### First migration and later updates

**Every old-brand installation must run the new installer once, including versions 1.1.0–1.5.0 with an updater.** Their updater pins the previous product ID, ZIP name, and archive root; the old `update --apply` cannot directly install this new-brand package.

1. Get `cy-charmyee-windows-v1.6.0.zip` and its `.zip.sha256` from the [official Releases](https://github.com/ScarfaceAI/CY-CharmYee/releases), verify and extract them, and confirm `name=cy-charmyee` in `bundle.json`.
2. Have the Agent run the new package's `scripts/install.ps1` as the same Windows user, or double-click `install.cmd`. Retain custom Agent, SkillsRoot, and state-location arguments. A single registration is discovered automatically; differing workspaces require one selection and are not merged.
3. Check the workspace, entrypoint, and backups in the installation receipt. Run local `doctor` and verify continuation with existing text, then reread the new `SKILL.md` or start a new conversation.

Once CY-CharmYee is installed, later updates use its new `update --apply` entry. Historical tags, asset names, and records remain unchanged. Publishing this version does not automatically upgrade the maintainer's everyday installation. See [installation](../../INSTALL.md) and [brand migration](../../references/brand-migration.en.md).

### Verification scope

Pre-publication local regression passed **210 tests**. Subsequent CI and PR fixes covered locked-file migration, stale analyses, profile-source links, and index recovery; **4 migration tests and 33 personal-knowledge tests** passed. The full suite now contains **215 tests**; final-commit CI and public-package evidence are recorded in the [verification record](../verification/v1.6.0.md) and this release's public verification appendix. All 7 Skills passed format validation. An independent isolated trial installed old 1.5.0, discovered its registration without Workspace / StateDirectory arguments, alternated old and new entries to finish the same text task, and read back all 6 saved knowledge files against their receipt hashes.

The installation trial used `-SkipDependencies` and synthetic data. It does not establish complete dependency installation, real credential decryption, cloud speech access, or automatic discovery in every host. Native `skills/list` on the everyday machine read back 6 existing primary entries and legacy compatibility entries; the new `CY-vault` was not installed there. Evidence for all 7 entries comes from isolation. CI, tags, and public ZIP verification follow the actual publication receipts.
