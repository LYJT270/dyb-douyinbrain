# 抖音脑 Douyin-brain 1.2.0

2026-11-05 · Windows

## 中文

这次更新让抖音素材获取和校对准备更适合后台使用。把链接和要求发给 Agent 后，常规获取在后台进行，不会自动弹出抖音浏览器或调用 Computer Use。

- 单条公开视频依次尝试普通 HTTP 分享页、全新无登录态的无头 Playwright，必要时尝试已有专用浏览器状态；保留 yt-dlp 的单视频回退。作者主页仍按实际分页结果检查完整性。
- 新增 `inspect-source --anonymous-only`，可不导入账号状态检查素材获取，也不调用语音识别。获取失败按实际原因报告；普通登录按钮不等于必须登录。
- 新增 `prepare-review`，按当前 Agent 实际可用的看图、听音能力准备文字、音频和帧图。默认帧图结合画面下半区域变化与 ASR 语句位置抽样，不是 OCR；指定区间可逐帧准备，超出帧数上限会报告缺口。准备材料不等于已经看图、听音或完成校对。
- 抖音登录不是安装前置。只有用户明确要求登录、验证或界面排障时才打开可见专用浏览器；登录与验证码由用户本人处理。豆包仍是默认语音识别服务；不会新增付费解析服务或自动录音。

识别原文保留、已有原始媒体不覆盖，校对稿另存；失败或结果未知的付费请求仍需先核对，再按用户明确要求重试。已有 1.1.0 及以上安装可继续请求「`@dyb-douyinbrain 更新`」或「使用 dyb-douyinbrain 更新自己」，1.0.x 用户先按[升级步骤](https://github.com/ScarfaceAI/dyb-douyinbrain/blob/v1.2.0/docs/RELEASING.md#已有用户如何升级)手动安装一次。

本地全量测试 **79 项通过，耗时 41.007 秒**，包括 14 项素材获取和无头浏览器测试、7 项校对准备相关测试；其中使用实际 FFmpeg 验证帧图和音轨准备，未调用真实 ASR。CI 与公开发布包待本次发布流程核验。

真实公开视频免登录获取到付费转写的完整链路、真实主页完整分页和各 Agent 的实际会话尚未完成验收。

## English

This update makes media acquisition and review preparation easier to use in the background. After you give an Agent a link and instructions, routine acquisition does not automatically open a Douyin window or use Computer Use.

- For an individual public video, try the ordinary HTTP share page, then a fresh headless Playwright browser without saved login state, and an existing dedicated browser state if needed. The yt-dlp single-video fallback remains. Creator-profile completeness still depends on actual pagination results.
- New `inspect-source --anonymous-only` checks acquisition without importing account state or calling speech recognition. Failures report the actual cause; a normal login button does not prove login is required.
- New `prepare-review` prepares text, audio, and frames according to the current Agent's actual image and audio capabilities. Default frames are sampled from lower-screen changes and ASR sentence positions, not OCR. A selected range can be prepared frame by frame; exceeding the frame limit is reported as a gap. Preparation does not mean the Agent has viewed, listened to, or reviewed the material.
- Douyin login is not an installation prerequisite. A visible dedicated browser opens only when the user explicitly requests login, verification, or interface troubleshooting; the user handles login and CAPTCHA. Doubao remains the default speech recognition service. No paid parsing service or automatic recording is added.

The machine transcript and existing original media are kept unchanged, with reviewed text saved separately. Failed or unknown paid requests still require checking before an explicitly requested retry. Existing installations from 1.1.0 onward can request “`@dyb-douyinbrain 更新`” or “Use dyb-douyinbrain to update itself.” Users on 1.0.x should first install this version manually using the [upgrade steps](https://github.com/ScarfaceAI/dyb-douyinbrain/blob/v1.2.0/docs/releasing.en.md#upgrading-an-existing-installation).

The full local test suite passed **79 tests in 41.007 seconds**, including 14 acquisition and headless-browser tests and 7 review-preparation tests. Real FFmpeg was used to check frame and audio preparation; no live ASR request was made. CI and the public release package remain to be verified during the release process.

The full live path from anonymous public-video acquisition through paid speech recognition, complete pagination of a real creator profile, and individual real Agent sessions have not yet been fully verified.
