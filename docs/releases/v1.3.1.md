## 中文

这个候选改善批量素材获取与识别的衔接，以及疑点区间的帧图准备；同时包含尚未公开发布的 [1.3.0 本地候选](v1.3.0.md)功能。

- 批量链接中，音轨已获取并验证的素材可先进入父进程的串行豆包识别，其余获取继续进行；每条获取阶段仍限时 90 秒，最多两个获取工作进程。重复素材去重，最终结果保留输入顺序和失败位置。
- 区间抽帧先定位所需位置，输出选定帧后停止；重叠区间可按源文件哈希与原始帧序号复用已校验的图片，时间戳对应同一原始帧，沿用既有 JPEG 质量设置。
- 批量失败逐条隔离，续跑先复用有效成功缓存；失败或结果未知的付费请求不自动重提。
- 常规获取在后台运行，不自动打开可见浏览器或调用 Computer Use。`run --anonymous-only` 可限制为匿名路径；`inspect-source` 可检查元数据或进一步验证音轨，不调用语音识别。
- 校对先通读全文、定位疑点，再按 Agent 的实际能力看图或听音。`prepare-review --cached-only` 只使用已有材料；准备材料不等于完成校对。
- 安装器可发现单套旧 `douyin-brain` 设置，沿用原工作目录和数据，备份旧配置与 Skill 并保留旧名兼容入口；多个不同工作目录由用户选择，不自动合并。

**本轮本地验证。** 匿名获取对照、流水线模拟、实际媒体帧图对照，以及 3 条真实语音识别和 Agent 校对交付已完成；浏览器优先试验因损失已有成功结果而撤销，3 条均未听音。最终本地全套回归通过 97 项。本机安装和迁移包状态另由本机回执记录，不代表公开发布。条件与结果见[本地验收记录](../verification/v1.3.1.md)。

## English

This candidate changes the handoff between batch acquisition and recognition and how frames are prepared for review ranges. It also includes the features from the unpublished [1.3.0 local candidate](v1.3.0.md).

- In link batches, media with acquired and verified audio can enter serial Doubao recognition in the parent process while other acquisition continues. The acquisition stage remains limited to 90 seconds per link and two workers. Duplicate media is deduplicated; final results retain input order and failure positions.
- Frame extraction seeks to the required position and stops after the selected frames are output. Overlapping ranges can reuse verified pictures by source hash and original frame index, with timestamps from the same original frames and the existing JPEG quality setting.
- Batch failures are isolated and valid successful caches are checked first on resume. Failed or unknown paid requests are not automatically resubmitted.
- Routine acquisition runs in the background and does not automatically open a visible browser or use Computer Use. `run --anonymous-only` restricts acquisition to anonymous paths; `inspect-source` checks metadata or additionally verifies audio without calling speech recognition.
- Read the full transcript and locate uncertainties before reviewing pictures or listening as the Agent's actual capabilities allow. `prepare-review --cached-only` uses existing material; preparation alone is not a completed review.
- The installer can discover a single legacy `douyin-brain` configuration, reuse its workspace and data, back up the old configuration and Skill, and retain an old-name compatibility entry. The user chooses between multiple differing workspaces; they are not merged automatically.

**This round's local verification.** The anonymous acquisition comparison, pipeline simulation, actual-media frame comparisons, and 3 live speech and Agent review deliveries are complete. The browser-first experiment was reverted after losing an existing success; none of the 3 audio tracks was listened to. The final full local regression passed 97 tests. Local installation and migration-package status will be recorded in separate local receipts and do not imply public release. See the [local verification record](../verification/v1.3.1.md) for conditions and results.
