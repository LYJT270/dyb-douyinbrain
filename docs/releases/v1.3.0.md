# 抖音脑 Douyin-brain 1.3.0 · 本地候选 / Local candidate

2026-11-06 · Windows

本候选尚未推送、运行本次 GitHub CI 或公开发布。This candidate has not been pushed, run through this candidate's GitHub CI, or publicly released.

## 中文

这次更新改善批量获取、续跑和校对准备。常规获取继续在后台进行，不自动打开可见浏览器或调用 Computer Use。

- 批量任务隔离每条失败并保留原序号；续跑先复用有效成功缓存。失败或结果未知的付费请求仍需核对，并在用户明确要求后才重试。
- 匿名获取使用网站自身页面的访客能力；只根据可见阻挡容器报告登录或验证要求。每条获取阶段限时 90 秒，最多两个获取工作进程，付费识别独立执行。
- `run --anonymous-only` 可限制使用匿名路径。`inspect-source` 默认只检查元数据，加 `--download-audio` 可继续验证音轨；该检查不调用语音识别。
- 校对先通读全文、定位疑点，再按 Agent 实际能力查看画面或听音。`prepare-review --cached-only` 只使用已有材料，缺失时报告而不联网补取；准备材料不等于已校对。
- 安装器可发现单套旧 `douyin-brain` 设置，沿用原工作目录及其中的数据，备份旧配置与 Skill 并保留旧名兼容入口。工作数据内嵌旧 Skill 时保留目录，只备份并替换入口。多个不同工作目录须由用户选择，不自动合并。

本机固定样本已实测匿名获取，并对其中 3 名不同作者的素材完成真实豆包识别及看图校对；部分素材获取失败，本轮没有听音复核。具体数量、测试条件与未验证项见[本地验收记录](../verification/v1.3.0.md)。

## English

This update improves batch acquisition, resumption, and review preparation. Routine acquisition remains in the background and does not automatically open a visible browser or use Computer Use.

- Isolate failures per item and retain original numbers. On resume, valid successful caches are checked first. Failed or unknown paid requests still require checking and an explicit user request before retrying.
- Anonymous acquisition uses the site's own visitor capability; login or verification is reported only from a visible blocking container. Acquisition is limited to 90 seconds per link and two workers; paid recognition runs separately.
- `run --anonymous-only` restricts acquisition to anonymous paths. `inspect-source` checks metadata by default; `--download-audio` additionally verifies audio. Neither inspection calls speech recognition.
- Read the full transcript and locate uncertainties before reviewing pictures or listening as the Agent's actual capabilities allow. `prepare-review --cached-only` uses existing material and reports missing evidence without fetching it; preparation is not a completed review.
- The installer can discover a single legacy `douyin-brain` configuration, reuse its workspace and data, back up the old configuration and Skill, and retain an old-name compatibility entry. If the workspace is inside the old Skill directory, it remains in place while only the entry files are backed up and replaced. The user chooses between multiple differing workspaces; they are not merged automatically.

The local fixed-sample test included anonymous acquisition, and material from three different authors went through live Doubao recognition and visual review. Some acquisitions failed, and no audio was listened to in this round. For counts, conditions, and unverified cases, see the [local verification record](../verification/v1.3.0.md).
