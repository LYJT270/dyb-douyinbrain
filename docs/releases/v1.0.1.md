# 抖音脑 Douyin-brain 1.0.1

2026-11-05 · Windows

## 中文

抖音脑是 Windows 本地 Agent Skill，可将抖音视频或本地音视频转写、校对、分析和整理为口播稿，也可处理已有文稿。

这是一个链接与署名更新补丁：GitHub 账号从 `LYJT270` 更名为 `ScarfaceAI`，本版本更新当前仓库链接与署名。**1.0.0 标签和发布历史保留，功能与安装行为未改变。**

安装时，从 [1.0.1 Release 页面](https://github.com/ScarfaceAI/dyb-douyinbrain/releases/tag/v1.0.1)下载 `dyb-douyinbrain-windows-v1.0.1.zip` 并解压，双击 `install.cmd`；也可将安装包交给有本地文件和终端能力的 Agent，按包内 `INSTALL.md` 安装。无需提前安装 Python。媒体转写需要用户自己的豆包语音 Key；没有 Key 时可以处理已有文稿。Key 在本机窗口填写，无需发到聊天里。

目前的验证记录包括 42 项自动测试通过，以及 GitHub Actions 干净 Windows 环境下的完整依赖安装和无 Key 文稿交付。真实付费语音识别和作者主页的真实完整分页尚未验证；各 Agent 的实际交互尚未逐一验收。

## English

Douyin-brain is a Windows-local Agent Skill for transcribing, proofreading, analyzing, and adapting Douyin videos or local media, and for working with existing text.

This patch updates links and attribution after the GitHub account was renamed from `LYJT270` to `ScarfaceAI`. **The 1.0.0 tag and release history remain intact; functionality and installation behavior are unchanged.**

To install, download `dyb-douyinbrain-windows-v1.0.1.zip` from the [1.0.1 Release page](https://github.com/ScarfaceAI/dyb-douyinbrain/releases/tag/v1.0.1), extract it, and double-click `install.cmd`. Alternatively, give the package to an Agent with local file and terminal access and follow its `INSTALL.md`. Python is not required in advance. Media transcription requires your own Doubao Speech key; existing text can be processed without one. Enter the key in the local window rather than sharing it in chat.

Verification to date includes 42 passing automated tests and a full dependency installation plus existing-text delivery without a key in a clean Windows environment on GitHub Actions. Live paid speech recognition and complete pagination of a real creator profile have not been verified; interactive sessions have not been individually verified across all Agents.
