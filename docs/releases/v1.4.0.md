# 抖音脑 Douyin-brain 1.4.0

2026-11-07 · Windows

## 中文

本版把抖音与音视频工作流整理为一个统一入口和五个专项 Skill，并加入博主主页分析与独立批量下载。用户可以直接描述需求，不需要记住命令；首次使用会介绍全部功能、适用场景、交付内容与配置需求，结果先在聊天中展示，文件作为补充。

### 功能与变化

- `dyb-douyinbrain` 处理组合需求、模糊需求与维护；`dyb-transcribe` 转写校对，`dyb-analyze` 分析账号、内容与选题，`dyb-download` 下载视频，`dyb-write` 改写文稿，`dyb-knowledge` 按明确要求归档与入库。六个入口共用安装、运行时、配置、缓存和版本。
- 博主主页逐页保存作品清单，保留来源、发布文案、时间和本次获取的互动数据。视频与图文参与分析，作品按时间组织；独立下载保存可访问的视频及配套发布文案，不调用语音识别。作品发现完整、素材准备完成和分析完成分别报告。
- 组合任务通过轻量 `work` 记录关联已有任务、依赖和实际产物；中断后可续跑，上游产物改变时会提示下游结果需要复核。原始文本、校对稿和改写稿分别保存。
- 新增付费识别按批次展示用量并取得授权，豆包仍是唯一语音识别服务。成功结果复用；失败或结果未知的付费请求不自动重试。确认未提交的音频额度可以释放，已提交或结果未知的部分保留记录。
- 后台素材获取采用有限并发，已准备音轨可先进入识别，结果保持输入顺序；同一作品的不同链接复用已验证音轨。抽帧按疑点区间准备并复用缓存。使用同一持久浏览器目录时串行访问，匿名上下文仍可并发。
- 限量分析和下载会跳过有效的已完成项；主页续跑保留未成功获取的作品身份。交付视频缺失或变化时如实报告缺口，恢复下载保留用户改动的文件。
- 安装与更新统一部署六个同级 Skill，避免重复发现；成员版本与哈希会校验，安装失败按事务恢复旧程序。安装默认按需配置语音和知识库，保留旧名称兼容入口与已有工作数据。

### 已有用户升级

使用 `1.1.0` 及以后版本时，可以对 Agent 说“使用 dyb-douyinbrain 更新”。更新从官方 Release 下载并校验整套程序；自定义安装继续沿用原工作目录和安装位置。`1.0.x` 用户先下载本页 Windows ZIP，解压后运行 `install.cmd`。更新后让 Agent 重读 Skill，或开启新会话。

`1.3.0` 和 `1.3.1` 是此前的本地候选；`1.4.0` 的新版本号使这些候选也能发现升级。已有任务与配置无需手动搬迁；首次功能介绍不等于新的付费授权。

### 验证与范围

功能合并版本已在 [Windows CI](https://github.com/ScarfaceAI/dyb-douyinbrain/actions/runs/42369906571) 通过 **159 项测试**、全新目录安装、无语音凭据的已有文本交付、安装包构建和清单／SHA 校验。发布流程会再次检查本版标签并校验公开下载。

本机 Codex 曾发现恰好六个启用入口，无重复。真实博主试验覆盖一次 69 条可见作品清单、两条视频识别和一条图文分析样本，不能据此声称整号内容已经全部分析；其他 Agent 的真实会话和所有平台场景未验证。详细范围见[套件验证](../verification/skill-suite.md)与[博主样本验证](../verification/creator-workflow.md)。本次发布准备不新增真实语音请求。

## English

This release organizes Douyin and audio/video workflows into one coordinator and five specialized Skills, and adds creator-profile analysis and independent batch download. Users can describe their goals directly. First use introduces every capability, expected output, and setup requirement; readable results are delivered in chat before supplementary files.

### Features and changes

- `dyb-douyinbrain` coordinates mixed or unclear requests and maintenance. `dyb-transcribe`, `dyb-analyze`, `dyb-download`, `dyb-write`, and `dyb-knowledge` handle transcription/review, account/content/topic analysis, video download, rewriting, and explicitly requested archiving. All six share installation, runtime, configuration, caches, and versioning.
- Creator discovery saves pages and source metadata incrementally. Video and image posts can be analyzed chronologically. Independent download saves accessible videos and captions without speech recognition. Discovery coverage, media readiness, and completed analysis are reported separately.
- Lightweight `work` records link existing tasks, dependencies, and actual artifacts. Work can resume after interruption, and changed upstream artifacts invalidate dependent results. Source text, reviewed transcripts, and rewrites remain separate.
- New paid recognition requires a batch usage preview and authorization. Doubao remains the only speech provider. Successful results are reused; failed or unknown paid requests are not automatically retried. Proven unsubmitted audio reservations can be released while submitted and unknown requests remain recorded.
- Bounded background acquisition overlaps with recognition of ready audio, retaining input order. Distinct links to one post reuse verified audio. Targeted frame preparation reuses matching caches. A persistent browser profile has one process owner until closure; anonymous contexts remain concurrent.
- Bounded analysis and download advance past valid completed items. Profile resumption retains unresolved media identities. Missing or changed delivered videos are reported as gaps, and recovery preserves user-modified files.
- Installation and updates deploy six sibling Skills with member-version and hash checks, avoiding duplicate discovery. Failed installation restores the previous suite. Speech and knowledge setup are requested only when needed; legacy aliases and workspace data are retained.

### Upgrading

On `1.1.0` or later, ask your Agent to “update dyb-douyinbrain.” The updater downloads and verifies the official suite while retaining the registered installation and workspace. On `1.0.x`, download the Windows ZIP from this release, extract it, and run `install.cmd`. Have the Agent reread the Skill or start a new conversation afterward.

`1.3.0` and `1.3.1` were local candidates; `1.4.0` also lets those installations discover this upgrade. Existing tasks and configuration do not require manual relocation. First-use presentation does not grant new spending permission.

### Verification scope

The merged feature version passed **159 tests**, fresh-directory installation, existing-text delivery without speech credentials, package construction, and manifest/SHA verification in [Windows CI](https://github.com/ScarfaceAI/dyb-douyinbrain/actions/runs/42369906571). The release workflow checks the release tag again and verifies the public download.

The local Codex installation discovered exactly six enabled entries without duplicates. Live creator trials covered one 69-post visible catalog, recognition of two videos, and analysis of one image post; they do not establish completed whole-profile analysis. Real conversations in other Agent applications and every platform scenario remain unverified. See the [suite verification](../verification/skill-suite.md) and [creator sample verification](../verification/creator-workflow.md). Release preparation makes no new live speech requests.
